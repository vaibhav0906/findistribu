# Findistribu Landing Page

A responsive Bootstrap-based landing page for **FinDistrib Hub**, showcasing AI-powered finance, logistics, and partnership tools for wholesalers and retailers.

## Features
- Hero section with gradient background, vivid trucking imagery, and clear CTAs.
- Feature grid highlighting credit rails, logistics intelligence, AI inventory, and partnerships.
- Prompt-to-product process section outlining the layered build approach.
- Partnerships showcase and strong CTA block for lead generation.
- Mobile-first layout with hover states, glassmorphism accents, and animated navbar styling.

## Getting Started
1. Open `index.html` in your browser, or serve locally:
   ```bash
   python -m http.server 8000
   ```
2. Visit `http://localhost:8000` to view the page.

## Customization
- Update brand copy directly in `index.html`.
- Tweak colors, gradients, and spacing in `assets/css/styles.css`.
- Adjust basic interactions (sticky nav styling, active link highlighting) in `assets/js/main.js`.
